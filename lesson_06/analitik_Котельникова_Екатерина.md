## Письмо 1. Ревью запросов

### Запрос 1. Заказчику нужны резюме с ожиданиями по зарплате от 100 000 ₽ и выше.

```js
db.resumes.find({ salary: { $gte: "100000" } })
```

- Решение: есть ошибка — значение не того типа: строка вместо числа или логического значения — верно
- Комментарий: Значение не того типа: salary хранится числом, а "100000" — строка. $gte сравнивает только в пределах одного типа BSON, поэтому 0 документов. Писать заказчику «таких нет» нельзя. Исправление: { salary: { $gte: 100000 } } — 4 резюме (Дроздова, Самойлов, Валиев, Пирогова).
- Исправленный запрос:

```js
db.resumes.find({ salary: { $gte: 100000 } })
```

### Запрос 2. Найти кандидатов с высшим образованием.

```js
db.resumes.find({ education: { level: "Высшее" } })
```

- Решение: есть ошибка — вложенный документ сравнивается целиком — нужна точечная нотация — верно
- Комментарий: Вложенный документ сравнивается целиком: { education: { level: "Высшее" } } ищет education, равный именно этому объекту, а в резюме там ещё другие поля. Нужна точечная нотация: { "education.level": "Высшее" }. Вывод «таких кандидатов нет» неверен.
- Исправленный запрос:

```js
db.resumes.find({ "education.level": "Высшее" })
```

### Запрос 3. Кандидаты, которые знают и SQL, и Python.

```js
db.resumes.find({ skills: { $in: ["SQL", "Python"] } })
```

- Решение: есть ошибка — не тот оператор для массива: $in вместо $all или наоборот — верно
- Комментарий: $in — это «хотя бы один навык» (ИЛИ), а задача — «и SQL, и Python». В выдаче 6 человек, включая знающих только один навык. Нужно $all: { skills: { $all: ["SQL", "Python"] } } — 4 кандидата. Шестерых заказчику отправлять нельзя.
- Исправленный запрос:

```js
db.resumes.find({ skills: { $all: ["SQL", "Python"] } })
```

### Запрос 4. Кандидаты, которые проработали в Retail Lab не меньше 12 месяцев.

```js
db.resumes.find({ "experience.company": "Retail Lab", "experience.months": { $gte: 12 } })
```

- Решение: есть ошибка — условия на массив документов выполняются в разных элементах — нужен $elemmatch — верно
- Комментарий: Без $elemMatch условия "experience.company" и "experience.months" могут выполняться на разных местах работы: Retail Lab — одно, 12+ месяцев — другое. Нужно, чтобы оба условия были в одном элементе: { experience: { $elemMatch: { company: "Retail Lab", months: { $gte: 12 } } } }. С исправлением результат 0, Дроздова попала в выдачу ошибочно.
- Исправленный запрос:

```js
db.resumes.find({ experience: { $elemMatch: { company: "Retail Lab", months: { $gte: 12 } } } })
```

### Запрос 5. Открытые вакансии в Москве, где верхняя граница зарплаты не меньше 160 000 ₽.

```js
db.vacancies.find({ city: "Москва", is_open: true, "salary.to": { $gte: 160000 } })
```

- Решение: запрос верный — верно
- Комментарий: Запрос верный: city и is_open — точные совпадения, salary.to через точечную нотацию с числом и $gte (границы включительно: 160000 попадает — отсюда администратор БД). Типы верны, 3 вакансии соответствуют задаче.

### Запрос 6. Все резюме на должности, в названии которых есть слово Python.

```js
db.resumes.find({ position: /python/ })
```

- Решение: есть ошибка — регистр букв: шаблон без флага i — верно
- Комментарий: /python/ чувствителен к регистру и не находит «Python» с заглавной буквы. Нужен флаг i: { position: /python/i }. Исправленный запрос находит 3 резюме, вывод «таких нет» неверен.
- Исправленный запрос:

```js
db.resumes.find({ position: /python/i })
```

### Запрос 7. Резюме с ожиданиями от 70 000 до 100 000 ₽ включительно.

```js
db.resumes.find({ salary: { $gte: 70000 }, salary: { $lte: 100000 } })
```

- Решение: есть ошибка — ключ в фильтре повторяется — первое условие пропадает — верно
- Комментарий: Ключ salary повторяется в объекте: второй затирает первый, остаётся только $lte: 100000, поэтому в выдаче Анна Белова с 65000 (ниже 70000) — 5 резюме вместо 4. Условия объединить в одном операторе: { salary: { $gte: 70000, $lte: 100000 } }.
- Исправленный запрос:

```js
db.resumes.find({ salary: { $gte: 70000, $lte: 100000 } })
```

### Запрос 8. Финальные собеседования в московских компаниях, которые проходили по видеозвонку.

```js
db.interviews.find({ "company.city": "Москва", format: "видеозвонок", stage: "финальное" })
```

- Решение: запрос верный — верно
- Комментарий: Запрос верный: company.city, format и stage объединены неявным AND, поля заданы корректно. Проверил: у всех 11 финальных видео-собеседований поле company.city есть, 3 в Москве — все в Яндексе, остальные 8 в других городах. Вывод коллеги совпадает с данными.
